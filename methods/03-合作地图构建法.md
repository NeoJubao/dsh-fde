# 03 · 合作地图构建法

> 目的：回答"**我们和这家客户到底能做什么**"——不是罗列产品，而是用**能力 × 缺口**交叉出合作空间。
> 关键：**必须写明"我们不做什么"**，否则会被当成又一家来抢地盘的供应商。

---

## 一、四步构建法

### 第 1 步：盘对方的"已有"（避免重复建设）

把客户已有的能力列全，**越具体越好**：

| 类别 | 要查清的内容 |
|---|---|
| 平台与系统 | 已建成什么平台、什么模型、什么功能模块 |
| 组织载体 | 是否已有自己的数智/科技子公司、研究中心、创新平台 |
| 数据资产 | 数据规模（条数/公里数/厂站数）、是否已治理 |
| 外部通道 | 是否有对外征集、揭榜挂帅、创新大赛、产学研机制 |
| 存量战果 | 已实现的量化成效（这是对方的能力证明，也是对标基线） |

> **本次实例**：对方已有大模型平台（671B + 本地蒸馏版）、知识库平台、零代码智能体开发平台、数智子公司、省级管网创新中心。→ **这些一律不能作为合作内容提出。**

### 第 2 步：盘我方的"能力"（对应能补什么）

把己方能力拆成**可对接的颗粒**，而非笼统的"AI 能力"：

示例拆法：数据与知识资产化 / 业务本体构建 / 业务 Agent 开发 / 治理制度设计 / 能力培训 / 联合交付。

### 第 3 步：交叉出机会矩阵

按客户**业务方向**分组（而非按我方产品分组），每组列 3–5 项：

| 字段 | 说明 |
|---|---|
| **合作机会** | 一句话说清做什么 |
| **具体内容** | 2–4 个动作 |
| **对接载体** | 客户内部哪个部门/公司/平台 |
| **可检查结果** | **必须可量化或可验收**，否则不是机会而是概念 |
| **卡点** | 数据、权限、组织、进度等约束 |

> **按客户业务分组**是这份图好用的关键——对方一眼能定位到自己的业务条线。

### 第 4 步：设计进入通道（怎么进得去）

不要只写"可以合作"，要写**从哪条门进去**：

| 通道类型 | 说明 |
|---|---|
| **官方征集** | 客户或其下属平台公开征集场景/技术（最合规、最快） |
| **揭榜挂帅** | 客户发布的攻关需求 |
| **生态/伙伴计划** | 客户正在构建的外部合作体系 |
| **产学研联合课题** | 联合申报科技计划 |
| **项目联合体** | 与客户体系内单位组成联合体承接项目 |

**通道要排序**：标明优先级与理由（合规性、速度、成功率）。

---

## 二、★ 边界纪律（本方法最重要的一节）

合作地图**必须包含"我们不做什么"**，作用是防止组织性抵触。

**写法**：用"不做什么 → 原因"的表格：

| 不做什么 | 原因 |
|---|---|
| ❌ 不建 XX 平台 | 客户已有并投用 |
| ❌ 不做 XX 平台 | 属客户下属某公司的产品线 |
| ❌ 不新建算力 | 客户已有 |
| ❌ 不替代专业判断 | 责任敏感 |
| ❌ 不与客户下属单位竞争，也不越过它直接对接 | **组织风险最高的一条** |

**与客户下属单位的关系设计**（当客户已有对口子公司时必写）：

```
客户总部
   ├── 下属数智公司（平台/底座）
   └── 业务子公司（场景/数据）
            ↓
      我方（业务层/治理层/能力层）
```
**协作三原则**：在对方平台之上工作、成果与知识资产归客户、**主动提出由对方下属公司牵头或共同交付**。

---

## 三、合作地图的标准章节

```markdown
# <客户> · 合作地图

## 一、合作空间全景
   （一张结构图：客户已有的 / ★合作空间 / 进入通道）
   + 定位一句话

## 二、合作机会矩阵（N 项）
   A. <业务方向一>（表格：机会/内容/载体/可检查结果/卡点）
   B. <业务方向二>
   C. <业务方向三>
   D. <治理与能力方向>

## 三、进入通道（按优先级排序）

## 四、★ 边界纪律（我们不做什么）

## 五、与客户下属单位的关系设计（如适用）

## 六、合作地图速查表（客户现状 → 我方补位 → 载体 → 通道）

## 七、本次会谈目标（对应本图位置）
```

## 四、质量自检

| # | 检查项 |
|---|---|
| 1 | 每项机会是否都有**可检查结果**（能量化或能验收）？ |
| 2 | 是否有任何一项与客户已有能力**重复**？ |
| 3 | 是否写明了**边界纪律**？ |
| 4 | 进入通道是否**具体到部门/平台/机制**，而非泛泛而谈？ |
| 5 | 机会是否按**客户业务方向**分组（而非按我方产品分组）？ |
| 6 | 是否标注了每项的**卡点**？ |
| 7 | 速查表能否支撑**现场 30 秒内定位**？ |

---

## 五、与"能力合作地图"的区别（避免混淆）

| 文档 | 视角 | 用途 |
|---|---|---|
| **能力合作地图** | 我方能力分层（资产本体 / Agent 底座 / 治理运营） | 内部对齐"我们的价值在哪一层" |
| **合作地图** | 客户业务方向 × 机会 | **对外沟通用**，客户能直接定位自己的业务 |

**两者配套使用**：内部先做能力分层，对外再翻译成客户业务语言。
