# ADR 0007 · 首页改为一屏四宫格（Today dashboard）

- 日期：2026-11-09
- 状态：已采纳（v1.6.0）
- 关联：`docs/ui-contract/layout.md` §2/§4/§7、`design.md`、`docs/01-spec.md` §8.1
- 回滚：`plugin-audit/fde-v2/06-实施/10-首页四宫格.md` 记录改动前后截图；UI 回滚用 `06-实施/` 快照 tar

## 背景

v1.5 的「今日」是**左 2/3 + 右 1/3 堆叠**：左侧「待我处理」很高，右侧「建议 / 今日焦点 / 最近活动」三张卡纵向叠，1440×900 下第三张卡要滚动才能看到；顶部问候卡 + 统计条又占约 150px。用户的实际诉求（原话）：

> 首页的布局是不是改一下 最好一页可以显示 4 宫格或者 4 列？再优化一下呢这里

问题拆解：

1. **一屏看不全**：四个信息块（待办/建议/焦点/活动）不是同级并列，右侧堆叠导致必须滚动；
2. **垂直空间浪费**：问候卡单独一行 + 统计条单独一行，占掉约 17% 的首屏；
3. **信息优先级不清**：四块里只有「待我处理」是 action（要我做），其余三块是 reference（我可以看），当前视觉权重却接近；
4. **窄屏**：`fde-grid-two` 在 900px 以下退化成单列长滚动，四块顺序与桌面一致但没有「先看什么」的引导。

## 决策

### D1. 目标结构：一行 KPI + 四宫格

```
content（今日，页型 inbox）
├─ .fde-today-head        固定高度（约 52–60px，不滚动）
│   ├─ 左：问候 + 一句战况（16/650 + 12 secondary）
│   └─ 右：4 个内联 KPI（数字 18/650 + 标签 11 secondary；活跃客户 / 待我处理 / 今日到期 / 逾期）
└─ .fde-today-grid        flex:1; min-height:0（页面级不滚动）
    ├─ panel 1 待我处理（action，主位，默认 1/4 宽）
    ├─ panel 2 建议
    ├─ panel 3 今日焦点
    └─ panel 4 最近活动
```

- 四块**同级**，每块 = 卡片（`bg-layer-1` + `border-l1` + 圆角 token），内部分「标题条 + 可滚动 body」；
- **页面级不滚动**（宽档）：四块各自 `overflow:auto`，标题条固定；
- 信息优先级靠**位置 + 标题 + 计数**表达，不靠加大卡片：待我处理仍是唯一带操作按钮的块；
- 顶部 KPI 去掉独立问候卡，只保留一行；统计数字仍只出现一次（`§2.6` 去重不破）。

### D2. 响应式三档（沿用 layout.md §3.2 的宽/中/窄定义）

| 档位 | 内容宽 | 布局 |
|---|---|---|
| 宽 | ≥1200 | **4 列**等宽（每列 ≈ (W−36)/4） |
| 中 | 900–1199 | **2×2 宫格**，两行等高、内部各自滚动 |
| 窄 | <900 | **单列**，允许页面滚动；顺序固定：待我处理 → 建议 → 焦点 → 活动 |

- 断点用 `@media (max-width: ...)` 实现（CSS 容器宽度，不是窗口宽度；面板可能被压窄）；
- 窄档不折叠成 tabs（避免多一层状态），保持纵向顺序即可；
- `1024×768` 属于窄档（内容宽 ≈1024−边距 <1200），按 2×2 或单列由实际内容宽决定；验收时两种宽度都要看。

### D3. 契约变更：inbox 用 `inbox-grid` 区域

`layout.md` 原 inbox = `primary` + `aside`（aside ≤1），无法表达四块同级。新增区域：

- `inbox-grid`：今日四宫格容器（仅 `inbox` 页型）；
- `primary` / `aside` 保留给 workbench / ledger / reference（语义不变）；
- `layout.md` §2 白名单 + `region-ids.mjs` 同步新增一行；`audit-ui-contract` A1 的「注册表 = §2 行数」保持 PASS。

### D4. 不做什么

- 不做可拖拽/可配置宫格（本期固定四块，避免引入布局持久化）；
- 不做「小部件市场」或自定义卡片；
- 不把待办/建议搬到页头（页头仍只放全局控件，见 layout.md §3.2）；
- 不改数据接口：`/fde/brief` 与 `/fde/board` 的字段不变，纯展示层重排。

## 后果

- 正面：1440×900 一屏看全四块；待办仍在主位；窄屏有明确阅读顺序；页面级滚动消失，长列表只在块内滚。
- 代价：每块可用宽度变窄（宽档约 300–340px），待办标题需要折行策略（`word-break`/两行截断）；建议/焦点/活动的空态要更紧凑，否则四宫格看起来很空。
- 未验证：真实宿主窗口宽度下的断点表现（离线 harness 按 1440/1024/820/700 截图验证，重启后需人工看一眼）。
