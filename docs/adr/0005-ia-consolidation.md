# ADR 0005 · 信息架构收敛：九页签 → 五页签 + 页头设置入口

- 日期：2026-11-09
- 状态：已采纳（Phase 2 实施，作为 v1.4.0 发布）
- 关联：`docs/ui-contract/layout.md` §7（导航准入与目标导航）、`docs/ui-contract/design.md`、`docs/01-spec.md` §8、`plugin-audit/fde-v2/03-设计审查与ui-contract.md`（D2/D3/D4/D9）
- 回滚：`.archive/` 快照 + `plugin-audit/fde-v2/06-实施/08-IA收敛.md` 记录（含改动前后截图）

## 背景

v1.3 面板有 9 个页签（今日 / 看板 / 客户 / 流程 / 资料库 / 招采 / 工件 / 方法 / 设置）。审查（2026-11-08）发现：

- 今日 / 看板 / 客户三处展示同一批客户对象，字段与操作三套 schema；
- 参考类（流程 / 资料库 / 方法）与配置类（设置）占着页签，违反 `layout.md` §7 的导航准入；
- 首屏重复控件（刷新 ×3、自主性徽章 ×2）与重复数字，A7 体检一直 FAIL；
- 9 个页签超过 VS Code / NN/g 等实践给出的 3–5 舒适上限。

`layout.md` §7 已给出目标态：5 页签 + 页头设置入口。ADR 0004 D8 曾明确把 IA 收敛延后到 Phase 2；本 ADR 记录 Phase 2 的实施决定。

## 决策

### D1. 目标导航（5 页签 + 页头入口）

| # | 页签 | 页型 | 覆盖旧页签 | 页内结构 |
|---|---|---|---|---|
| 1 | **今日** | inbox | 今日 | 战况 / 待我处理（按 kind 分组折叠）/ 建议 / 今日焦点 / 最近活动 |
| 2 | **客户** | workbench + ledger | 看板 + 客户 | 视图切换：**看板（客户列 / 任务列）/ 客户清单**；卡片与清单共用对象 schema |
| 3 | **资料** | reference + ledger | 资料库 + 招采 | 子页签：**资料库 / 招采** |
| 4 | **流程** | reference | 流程 + 方法 | 子页签：**8 阶段流程 / 方法库 / 技能与模板** |
| 5 | **文件** | ledger | 工件 | 产物台账（按客户/阶段聚合、Finder、按需导出） |
| — | **设置** | settings | 设置 | 页头齿轮入口，不占页签；返回上一主视图 |

### D2. 深链与状态

- 内部 `view` 状态收敛为 `today | customers | library | process | files` + `settings`（页头入口）；旧值（`board` / `artifacts` / `methods` / `bids`）统一 `normalizeView()` 回落：`board→customers`、`artifacts→files`、`methods→process`、`bids→library`。
- 阶段工具 chips / 客户抽屉 / 详情跳转全部指向新页签 + 子页签，不留死路由。
- 不再新增页签；新功能只能进现有页签的区域（落位规则见 `layout.md` §1 决策树）。

### D3. A7（重复全局控件）清零

- 壳层保留**唯一一处**「刷新 + 自主性徽章」；各页签内部删除重复的页内刷新/自主性控件。
- 块级刷新（资料库、招采、文件各自的「刷新本块数据」）保留：它们刷新的是块，不是全局 board。

### D4. 断言与文档同步

- `docs/01-spec.md` §8 重写为目标 IA；§17/§19.6/§20.5 的「第 N 页签」表述改为「子页签/子视图」。
- `verify/acceptance-audit.mjs` 的九页签断言改为 5 页签 + 子页签；README/AGENTS 的「九视图/九页签」表述同步。断言只同步口径，不放宽/删除。
- ui-contract 体检 A7 应从 FAIL 转 PASS；若仍 FAIL，说明页内重复控件未清干净。

## 后果

- 正面：首屏与导航更短；同一对象只有一套呈现；A7 清零；与 `layout.md` §7 目标态一致。
- 代价：用户需要一次适应（旧页签位置变化）；旧 hash/深链不保证兼容（插件内状态，非外部 API）。
- 未做：不改宿主半与数据模型；不改阶段/泳道/门禁定义；不改抽屉信息架构（L2 返回栈留待后续）。
