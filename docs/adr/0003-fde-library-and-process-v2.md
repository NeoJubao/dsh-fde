# ADR 0003 · FDE 资料库与流程 v2（v1.3）

- 状态：已确认（Lead 起草，2026-11-04；依据 Neo 2026-11-04 明确要求）
- 影响版本：v1.3（spec §19–§21）
- 关联：`docs/01-spec.md` §19–§21、`docs/02-plan.md` §4、`docs/retros/`

## 背景

v1.2 把「生财」做成第 8 页签。Neo 2026-11-04 提出：①把该栏目升级为 **FDE 资料库**，收录国外官方（OpenAI/Claude 等）、国内大厂（腾讯/阿里等）、GitHub 开源工具等权威资料，每日更新、重点推荐标注；②完善 FDE 流程阶段与工具，重点补「场景选择」与「成本评估/报价」两个真实痛点（当天下午在某制造企业与某制药企业两个客户上暴露）。

## 决策

### D1 · 「资料库」替换「生财」页签，生财降为「社区动态」来源
- 资料库 = 策展目录（官方一手 + 开源 + 方法模板）+ 社区动态（生财）合并入口；重点推荐与筛选按来源组组织。
- `fde-scys.js` 与 `scys-fde.json` 保留；`scys_fde` 工具保留兼容；面板不再单独设生财页签。
- 理由：用户要的是「权威资料集」，生财是来源之一而非全部；避免丢弃 v1.2 已验证的抓取/缓存/降级能力。

### D2 · 策展目录随插件发布，每日只刷「可核实指标 + 社区摘要」
- `reference/fde-library/catalog.json` 人工策展（A/B/C 分级、URL 实测、阶段标签、推荐等级）；GitHub 指标与社区摘要在宿主每日刷新。
- 不抓任意网页正文：版权、反爬、噪音与不可控抓取风险；「每日更新」的口径如实为「指标/社区更新 + 新增标注」，不是「官方文档每日变化」。
- 理由：可离线、可测试、可解释；权威性靠人工核验而非自动抓取。

### D3 · 流程由 7 阶段改为 8 阶段，新增 `scoping`（场景）
- 进入方案前必须先把需求池收敛到可启动场景：四条硬门槛（有姓名发起人 / 14 天首次集成 / 90 天上线 / 使用可测）+ 数据体检 + 范围确认。
- `solution` 门禁新增成本测算与报价单；「成本/报价」进入流程而不是寄望于临时发挥。
- 理由：当天两个真实痛点分别是「场景选择」和「成本报价」；现有 7 阶段没有承载点，只能散落在方案/会面里。

### D4 · 用确定性计算工具承载两个痛点，而不是让模型自由发挥
- `fde_scenario`（四门槛 + 加权评分）与 `fde_quote`（人天/非人力/预备费/税/毛利/报价区间）为纯函数，返回 Markdown；费率与甜点区放可编辑配置 `reference/fde-pricing.json`。
- 明确标注「方法默认值、不构成对外报价」；对外报价仍由人确认（红线不变）。
- 理由：可复算、可测试、可审计；避免模型幻觉数字。

### D5 · 面板新增「流程」页签，保留「方法」页签
- 导航 9 项：今日 / 看板 / 客户 / 流程 / 资料库 / 招采 / 工件 / 方法 / 设置。
- 「流程」= 阶段地图 + 每阶段输入/动作/交付物/工具/坑（从 `/meta` 派生）；「方法」= 内部方法/模板/技能库（原能力保留，避免大改）。
- 理由：流程是用户这次的核心诉求，需要独立入口；方法库已有稳定实现，不合并以降低回归风险。

## 备选与取舍

| 备选 | 否决理由 |
|---|---|
| 保持 7 阶段，把场景选择做成研判子步骤 | 没有门禁承载，客户可跳过；无法回答「阶段对应什么工具」 |
| 资料库直接爬取官方站点/RSS 每日更新 | 站点反爬/403、版权与噪音不可控；无法保证「权威」；测试需联网 |
| 让 LLM 给场景打分/报价 | 不可复算、不可审计；用户要的是可复核的底稿，不是第二个意见 |
| 新建独立插件/独立仓库 | 破坏「看板唯一编排」与现有部署方式（link 安装、单插件） |
| 合并「方法」进「流程」 | 回归面大、现有 MethodsView 稳定；9 页签横向可滚动，成本低 |

## 后果与约束

- 需要更新 schema/门禁/面板/技能/文档/验证；旧 board 无需迁移，已在后续阶段的客户不被降级。
- `solution` 门禁新增自动项会让部分存量客户显示缺项；按 spec §20.2 补材料或由人 `force` 留痕。
- 资料库的「每日更新」必须如实展示来源状态（GitHub 失败/社区缓存过期不可伪装成全绿）。
- 回滚：解包 `.archive/research-workbench-pre-v13-*.tar.gz`；`research/.fde/fde-library.json` 可直接删除（缓存类）。
