# ADR 0008：资料页重构与内嵌预览（v1.7）

- 状态：已接受（2026-11-11）
- 决策人：Lead（Neo 提出用户反馈：资料管理麻烦、文件列表信息过载、缺预览、调研类信息混入）
- 关联：`docs/01-spec.md` §8.3/§8.5、`docs/adr/0005`（5 页签 IA）
- 回滚：客户端改动集中在 `src/ui/ui-panel.js`；`git checkout -- client.js` + 重跑 `node build.mjs` 即回退（无宿主路由/数据迁移）。

## 背景

v1.4 起主面板为 5 页签（今日/客户/资料/流程/文件）。实测「文件」页：

- 首个客户展开后渲染 **413 个文件**（`raw/` 336 个），按目录平铺，一屏信息量过大；`raw/**/*.html|json|txt` 等抓取副产品与交付物混排，正是用户说的「很多调研类的信息也展示了」。
- 每行 2–4 个按钮（导出 PDF/质检/Finder 显示/打开），主操作不明确；只支持「在 Finder 显示 / 系统应用打开」，**没有任何内嵌预览**，看一份 md 或 PDF 必须离开工作台。
- 页签名「资料」（资料库+招采，调研情报）与「文件」（客户资料）语义冲突，用户口语里的「资料管理」指后者。

## 决策

1. **命名**：页签「文件」→「资料」（客户资料）；页签「资料」→「情报」（资料库+招采）。视图 key 不变（`files`/`knowledge`），只改文案，避免路由/状态迁移。
2. **资料页改为 master-detail**：左列文件列表（可搜索/类型筛选/原始素材开关/按客户或最近分组，默认「最近资料」），右列固定预览面板；窄屏（<1000）预览覆盖列表并可返回。
3. **默认只显示「关键资料」**：`raw/` 路径或扩展名属于 `html/htm/json/xml/tsv/log` 的文件归为「原始素材」，默认折叠并可一键显示（带计数）；其余（md/pdf/docx/xlsx/pptx/图片/csv 等）默认可检索。
4. **预览复用宿主能力，不新增路由、不加依赖**：
   - 文本/md/txt/code/html 源、PDF、图片：同源已鉴权路由 `GET /api/file?path=<abs>`（自动跟随 302 版本重定向；50 MiB 上限）。
   - Word/Excel/PPT：客户端远程服务 `remote.officeToPdf.render(sessionId, path, 'foreground')` 转 PDF 后内嵌；`sessionId` 从 `sessions` 服务快照中取当前工作区（cwd 在 root 下）的会话。无会话时降级为「用系统应用打开」提示（诚实说明，不伪造预览）。
   - 不直接复用右侧栏原生预览：实测面板态 `sidebarRight` 报 `no session surface is mounted`。
5. **交互收敛**：行主操作 = 预览（整行可点）；「Finder 显示 / 系统应用打开 / 复制路径」收进行尾溢出菜单；md 的「导出 PDF/质检」移到预览头部。
6. **不做**：编辑/重命名/删除/移动文件、批量导出、新增宿主路由、动宿主侧栏、抓取任意网页正文。

## 后果

- 首屏从「413 行 × 2–4 按钮」变为「按客户分组的少量关键资料 + 明确筛选」，默认信息量下降一个量级。
- 看 md/PDF/图片/Office 不再离开工作台；Office 预览依赖会话存在（如实降级）。
- `verify/client-static.mjs` 等文案断言需同步；经典模式（旧五页签）保留，不受影响。
- 已知限制：HTML 快照以 sandbox iframe 静态渲染（不执行脚本、相对资源可能缺失）；超大文本截断提示；Office 首次转换可能慢（宿主转换队列）。

## 追加（2026-11-11，真机反馈后的最终取舍）：预览留在面板内

用户反馈「资料预览用 DSH 自带的那个预览，像我点击 spec 一样」。实测与原型验证结论：

- DSH 0.2 的右侧栏文档预览（`sidebarRight.openResource`）只在**选中会话界面**时渲染；FDE 面板是独立 main 面板，面板态调用报 `no session surface is mounted`。
- 让面板态可用有两条路：① 点资料先切到会话再开预览（会离开资料页）；② 把 FDE 挂成会话的一个 View（FDE 内容保留 + 右侧原生预览，但会话顶部多一个 View 标签、底部仍显示聊天输入框）。
- **用户明确选择：不跳走，不用原生预览。** 因此最终形态：点资料行 = 面板内内嵌预览（md/PDF/Office/图片/HTML 都渲染在右列），不切换主面板；行尾「⋯」保留系统打开/Finder/复制路径；预览头部保留导出 PDF/质检/重新加载/全屏。
- 面板内渲染器继续复用宿主能力（`/api/file`、`remote.officeToPdf`），零新增路由/依赖；原生预览的约束与两条备选路径记录在此，若 DSH 后续支持面板态右侧栏可再切换。
- 返回连续性：`FDE_VIEW_MEM`/`MAT_UI_MEM` 记住页签与筛选（内存，刷新即重置）。

### 追加（2026-11-11，1280 窗口下的「上下结构」修复）

真机窗口约 1280 逻辑宽时，早期用 `@media (max-width:1280px)` 把列表与预览改成上下堆叠，观感怪异且不好用。根因：**窗口宽 ≠ 面板宽**（宿主左侧栏占约 280px）。修正：

- 断点改为容器实测宽度（`ResizeObserver` 观察资料页根节点），面板 ≥860px 保持左右并排；<860px 走单列切换（列表 ⇄ 预览），预览头部给「‹ 返回列表」，不做上下堆叠；
- 窄面板下不自动选中文件（否则一进页面列表就被预览顶掉）；从宽变窄时若只是首屏自动选中则退回列表；
- 1280 逻辑宽窗口下面板约 964px → 左右并排（已真机验证）；1100 窗口下面板约 784px → 单列切换（已真机验证返回按钮）。

### 追加（2026-11-11，可拖动分隔条）

资料页列表/预览之间加一条可拖动分隔条（`role=separator`、`aria-orientation=vertical`）：

- 鼠标拖动实时调整列表宽度，限制 300px ～ （面板实测宽 − 320px）；
- 键盘可达：←/→ 每次 16px、Shift+←/→ 48px、Home 最窄、End 最宽；聚焦有 focus ring；
- 宽度记在模块内存（`MAT_UI_MEM.listWidth`），切换插件面板/页签返回后保留；刷新页面重置；
- 面板实测宽 <860 的单列模式不渲染分隔条（无意义，避免误操作）。
