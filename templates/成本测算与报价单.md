### 1.1 汇总（按 `fde_quote` 公式）

| 项 | 计算 | 金额（元） |
|---|---|---:|
| 人力合计 | Σ(人天 × 单价) | |
| 非人力合计 | 第 5–12 项（不含税项单列） | |
| 直接成本 | 人力合计 + 非人力合计 | |
| 风险预备费 | 直接成本 × __%（默认 15%） | |
| **成本合计** | 直接成本 + 预备费 | |
| 税（价外） | 不含税目标价 × __%（默认 6%，示例） | |
| **报价（含税）** | 成本合计 ÷ (1 − 毛利率) × (1 + 税率) | |

> 校验：成本合计 = 直接成本 + 预备费；报价含税 ÷ (1+税率) = 不含税目标价；不含税目标价 × (1−毛利率) = 成本合计。

## 2. 三点估算（仅对不确定性高的角色使用）

```
te  = (o + 4m + p) / 6          # P50 基准
σ   = (p − o) / 6
P80 = te + 0.84 × σ             # 计价人天，向上取 0.1 人天
```

| 角色 | 乐观 o（人天） | 最可能 m | 悲观 p | te（P50） | σ | P80（计价） | P80 × 单价（元） | 依据 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| | | | | | | | | |
| | | | | | | | | |
| **合计** | | | | | | | | |

> 报价按 P80 计价、内部成本基线按 P50；σ 大说明信息不足，先补数据/接口再报价。

```jsonc

    { "name": "FDE/算法", "personDays": 18, "rate": 1200 },
    { "name": "工程师", "optimistic": 8, "likely": 10, "pessimistic": 14, "rate": 940 },
    { "name": "数据与评测", "personDays": 8, "rate": 800 }
  ],
  "defaultRate": 940,
  "nonLabor": {
    "dataEval": 7000,
    "cloudToken": 5000,
    "compliance": 5000,
    "ops": 8000,
    "travel": 3000,
    "quality": 2000,
    "other": 0
  },
  "contingencyPct": 15,
  "taxPct": 6,
  "marginPct": 35,
  "discountPct": 0,
  "teamSize": 3,
  "weeks": 10
}
```

| 本表位置 | `fde_quote` 参数 | 对应 10 类成本 |
|---|---|---|
| 第 1 节序号 1–4 | `labor[]`（`name/personDays` 或 `optimistic/likely/pessimistic`；`rate` 可省用默认） | 人力 |
| 第 1 节序号 5–6 | `nonLabor.dataEval` | 数据与评测 |
| 第 1 节序号 7 | `nonLabor.cloudToken` | 云与 token |
| 第 1 节序号 8 | `nonLabor.compliance` | 合规 |
| 第 1 节序号 9 | `nonLabor.ops` | 运维 |
| 第 1 节序号 10 | `nonLabor.travel` | 差旅 |
| 第 1 节序号 11 | `nonLabor.quality` | 质保 |
| 第 1 节序号 12 | `nonLabor.other` | 渠道/居间（不写敏感明细） |
| 第 1.1 节预备费 | `contingencyPct` | 风险预备费 |
| 第 1.1 节税 | `taxPct`（价外税，不进 `totalCost`） | 税 |
| 第 3 节毛利/折扣 | `marginPct` / `discountPct` | 定价 |
| 团队/周期校验 | `teamSize` / `weeks` | 人天与周期匹配告警 |

> 工具返回 `summary` 与 `warnings[]`；`warnings` 必须逐条处理（接受/修数），不能静默忽略。
> `action=template` 可返回空白模板；配置缺失/损坏时用内置默认值并给 warning，费率以 `reference/fde-pricing.json` 为准。

- [ ] 数据评测、云 token、合规、运维、质保五项无漏列（0 值有理由）。
- [ ] 三点估算的 o/m/p 有来源；P80 计价、P50 基线已注明。
- [ ] 报价单含 out-of-scope、假设与客户责任、除外、变更、验收质保、有效期。
- [ ] 金额口径分离（估算/控制价/成交价）；含税/不含税写明。
- [ ] 毛利率 ≥20%（<35% 需人确认）；预备费未因砍价被砍。
- [ ] token/云/驻场有年度封顶与超量单价；报价有效期覆盖合规等待期。
- [ ] token 单价已按官方定价页现查；所有费率/毛利/合规费用已标「经验区间/方法默认值」。
