# 长文一页纸（brief）· 写作规范

> **用途**：长文（≥5 节的报告、方案、评估、复盘）**必须另出一份一页纸（brief）**。
> 一页纸是**长文的单页摘要**，不是「ASD-STE100 标准说明」，也不是目录。读者拿一页纸就能做判断，不必读长文。
> **执行技能**：`longdoc-brief`（`research-workbench-plugin/skills/longdoc-brief/SKILL.md`，含一页验收脚本）。
> 配套：写作按 ASD-STE100 原则（内部写作目标，自评口径不写进成品）；规范版本 v1.1｜2026-11-05。
> 标准速查见 `research-workbench-plugin/reference/ASD-STE100-简写标准-brief.md`。

---

## 0. 术语（先统一叫法）

| 叫法 | 指什么 | 不是什么 |
|---|---|---|
| **长文** | 正文 md，唯一事实源 | 不是一页纸 |
| **一页纸（brief）** | 长文的单页摘要，固定 7 块 | 不是目录、不是标准说明、不是第二份长文 |
| **阅读版** | 一页纸的交互 HTML 形态。屏幕阅读用；打印也只出一页 | 不是另一种内容 |
| **传阅版** | 一页纸的 A4 单页 HTML 形态。打印、转发用 | 不是另一种内容 |

停用叫法：

- 「一页摘要」= 一页纸的口语说法，同一个东西，不单独当名词。
- 「交互版」→ 改叫「阅读版」。
- 「一页版」「内部传阅版」→ 改叫「传阅版」（「内部」只说明用途）。

## 1. 一句话定义

**一页纸 = 一页内说清：结论是什么、依据是哪几个数、建议做什么、要谁拍板、风险在哪。**

三不要：

- 不要复述长文结构（不要「第一章…第二章…」）。
- 不要新增长文没有的结论。
- 不要做成标准说明或方法论文。

## 2. 必含 7 块（顺序固定）

| # | 块 | 内容 | 一页位置 |
|---|---|---|---|
| 1 | 标题与一句话结论 | 对象 + 结论，一句话 | 顶部 |
| 2 | 3 个关键数 | 支撑结论的三个硬数字 | 标题下横排 |
| 3 | 判断表 | 每个候选项一行：判定 + 一句依据 | 中部 |
| 4 | 建议 | 主攻 / 次选 / 保底 / 不做；每项带前置条件 | 中下部 |
| 5 | 要人拍板的事 | 3–5 条，每条一句 | 下部 |
| 6 | 风险 top 3 | 只列最可能发生的三条 | 下部 |
| 7 | 元信息 | 密级、日期、来源长文 | 页脚 |

## 3. 写作规则（STE 原则，内部目标）

- 一句一个动作或一个判断。中文单句 ≤35 字。
- 主动语态；执行者写清楚（我方 / 客户 / 系统）。
- 一词一义；同一概念只用一个说法；缩写首次出现给全称。
- 段落 ≤6 句；一节只讲一件事。
- 警示、前提、边界单独成句或独立成块。
- 不写隐喻、口语、夸张、营销词。
- 客户原话、数字、单位原样引用；不换算、不合并。
- 成品里**不写自评分数、标准说明、认证声明**；自评与句长实测只记在内部底稿。

## 4. HTML 交付要求

| 项 | 要求 |
|---|---|
| 自包含 | 单文件；无外部字体、脚本、图片依赖；离线可开 |
| 阅读版（交互 HTML） | 页签切换、深浅色、复制摘要、勾选、打印按钮、键盘快捷键（至少 1–6 切页签、P 打印、T 换主题） |
| 打印 | 打印时只输出**传阅版**，A4 单页，无导航与按钮 |
| 传阅版（A4 单页） | 另出一个独立单页 HTML：A4 版式、无交互、可直接转发或打印 |
| 可访问 | 语义标签、对比度达标、焦点可见、减少动效偏好（prefers-reduced-motion） |
| 可追溯 | 页脚写长文路径、生成日期、密级 |

## 5. 文件命名与落盘

- 阅读版：`research/<客户>/<阶段>/exports/<主题>-brief.html`
- 传阅版：`research/<客户>/<阶段>/exports/<主题>-brief-传阅版.html`
- 文件名保留 `brief`：`brief` 就是一页纸，不另造第二个文件名。
- 长文正文仍以 md 为准；一页纸与长文冲突时，以长文 md 为准。
- 客户卷内的一页纸默认 L3 内部件；要外发先改密级与措辞，并由人确认。

## 6. 验收清单（发布前逐条勾）

- [ ] 一页能读完；打印只出一页 A4。
- [ ] 一句话结论 ≤60 字。
- [ ] 关键数 3 个，均有长文出处。
- [ ] 判断表覆盖全部候选项；每项一句依据。
- [ ] 建议带前置条件；不做的项写明原因。
- [ ] 拍板事项 3–5 条，每条一句。
- [ ] 风险只留 top 3。
- [ ] 句长实测：≤35 字句占比 ≥85%（只记内部底稿）。
- [ ] 页脚有密级、日期、长文路径。
- [ ] 成品不出现自评分数、标准说明、「符合标准」「通过认证」字样（内部底稿可留）。

## 7. 本工作区当前示例

| 长文 | 一页纸 · 阅读版 | 一页纸 · 传阅版 |
|---|---|---|
| `scoping/场景评估.md` | `scoping/exports/首期上线场景-brief.html` | `scoping/exports/首期上线场景-brief-传阅版.html` |

- 其他：一段 ≤6 句；主动语态；简单时态；不用 -ing 动词形式；名词串 ≤3 词；警示独立；技术名词可自定但须定义并一致。
