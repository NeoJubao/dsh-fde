# 领域模型合作技能

> **定位：本技能是方法库，由 `fde-solution` 编排，不要独立自动触发。**
> 需要产出合作方案、多方分工建议或对外材料时先用 `fde-solution`（客户调研由 `fde-discovery`、会面材料由 `fde-meeting` 承接）；本技能只提供六层框架、角色设计与雷区。

> 输入：客户单位 + 其承担的领域（或上级规划）+ 已有/拟引入的模型方
> 输出：**六层分工建议（一页纸）** + 会谈底稿 + 现场 Brief + 实施方案
> 方法论全文：`methods/04-领域模型合作方法论.md`

## 一、铁律（先读这四条）

### 铁律 1：领域模型只是六层中的一层

**最常犯的错**：把"建领域模型"当成整个项目。**实际必须建六层**：

```
① 模型层   基座选型/微调/蒸馏/算力/评测工具链   → 模型方主责
② Agent 层 系统级智能体、自助创建/管理/优化、
           多智能体任务协作、过程记录与结果验证  → 我方主责
③ 数据层   领域数据集、知识资产、业务本体        → 我方 + 客户
④ 平台层   算力、平台、工具链、涉密部署环境      → 客户/集团（勿重复建设）
⑤ 场景层   高价值、可闭环、可验证的业务闭环      → 客户牵头 + 我方工程化
⑥ 机制层   组织、责任矩阵、评估、培训、能力移交  → 客户（我方供方法）
```

**只谈模型层 → 我方没有位置；摊开六层 → 我方在 ②③⑤⑥ 四层有主责。**

### 铁律 2：先弄清客户在"大盘子"里的真实角色

**绝不要假设客户是大总包。** 必问三句：

1. 这件事是**上级/集团层面规划**，还是**本单位自主**？
2. 本单位承担的**是其中哪一块**？（例：集团规划十大领域模型，客户只承担**其中一个领域**）
3. 有无**依据文件**（规划、通知、专项）？

> 角色判断错了，材料的层级、话术、交付物**全错**。

### 铁律 3：数据出域边界决定方案可行性

涉密/军工场景下，**训练数据能否出域是全案决定性前提**，必须**最先确认**。

- 优先：全流程**内网本地化**训练
- 次选：**脱敏后出域** + 外部方**驻场**
- 兜底：**客户团队执行 + 外部供方法与工具**（外部方资质不足时）

### 铁律 4：核实合作方全称，防同名不同主体

**实例**：**智谱华章**（北京智谱华章科技，GLM，港股 02513.HK）≠ **中航智谱**（成都，中国航空工业集团 AVIC 持股）。分属不同央企体系，谈错对象等于全盘作废。

## 三、把客户上级的战略语言变成话术骨架

**做法**：抓客户**上级单位/集团**的公开会议原文，用其**原词**做我方材料骨架。

**实例（某航发集团 → 某研究院）**：

| 上级原文（A 级） | 材料中的用法 |
|---|---|
| "**加电赋智、增数加算**"行动 | 开场引用，证明做过功课 |
| **四大短板**：能力建设碎片化、数据资源孤岛化、应用成效表层化、前沿跟进迟滞化 | 六层框架**逐条对应解法** |
| "**通用AI + 工程专业 + 组织闭环**"复合能力 | ②Agent + ⑥机制 的定位依据 |
| "**高价值、可闭环、可验证**"的场景 | ⑤ 场景层的**准入与验收标准** |
| "**行业共享的高质量数据集**" | ③ 数据层目标表述 |
| "**算力、平台和工具**等关键基础设施" | ④ 平台层（明确我方**不重复建设**） |
| "**明确各类主体责任**" | 直接支撑"责任矩阵一页纸"交付物 |
| **三年滚动计划** + "AI4E2""AI4S"先锋项目 | 三阶段节奏的对齐依据 |
| "每位学员提交**本单位本领域 AI 应用速赢速效项目初步规划**" | ★ 判断客户**手上有硬任务**，材料据此定位 |

**四大短板 → 六层解法映射**：

| 短板 | 解法所在层 |
|---|---|
| 能力建设碎片化 | ⑥ 机制层：统一范式 + 责任矩阵；先样板再复制 |
| 数据资源孤岛化 | ③ 数据层：业务本体让数据可关联、可追溯、可推演 |
| 应用成效表层化 | ⑤ 场景层：准入标准与验收指标**前置** |
| 前沿跟进迟滞化 | ① 模型层：与前沿方建立持续合作机制 |

## 四、三方角色设计法

### 4.1 每个合作方填三栏

| | 客户 | 模型方 | 我方 |
|---|---|---|---|
| **核心资产** | 领域知识与场景、专业人才 | 基座模型、训练推理工程、算力适配 | 业务本体方法、Agent 编排与治理、FDE 交付 |
| **为什么需要它** | 没有领域知识训不出模型 | 从零做模型代价过高 | 没有这层，模型训完**用不起来** |
| **最怕什么** | 训完模型没人用、数据出不去 | 场景不清晰、验收标准不明 | 被当成"又一个外包" |

### 4.2 必须写出"谁都别做别人更擅长的事"

- ❌ 我方不做基座训练、不做算力供给 → 模型方
- ❌ 模型方不做领域知识结构化与业务本体 → 我方 + 客户
- ❌ 客户不从零搭平台/算力 → 承接上级已有布局
- ❌ 我方不重复建设平台、不与模型方争模型层
- ❌ 任何一方都不替代人工决策与签发

### 4.3 我方的六条不可替代价值（按六层归位）

| # | 价值 | 所在层 |
|---|---|---|
| 1 | 把领域知识变成模型能学的东西（业务本体、数据集构建、知识资产化） | ③ |
| 2 | 补齐模型之外的 Agent 层（创建/管理/协作、过程记录与结果验证） | ② |
| 3 | 组织"可闭环、可验证"的场景（FDE 深入业务前线） | ⑤ |
| 4 | 多方之间的工程协调与交付管理 | 跨层 |
| 5 | 让能力留在客户（培训与知识资产移交） | ⑥ |
| 6 | 可复制的建设范式（治"能力建设碎片化"） | ⑥ |

## 五、现场必问四题

1. **客户承担的是哪一个领域**？（上级规划里本单位的那一块）
2. 与模型方的合作**目前到什么阶段**（接触 / 框架 / 试点）？
3. **训练数据能否出域**？合规路径如何走？
4. **模型之外（Agent 层、数据层）希望谁来做**？★ 我方切入口

## 六、雷区（九条）

| # | 雷区 | 后果 | 防法 |
|---|---|---|---|
| L1 | 把客户当成大总包 | 材料层级全错 | 先问"上级规划还是自主、你承担哪块、有无依据文件" |
| L2 | 只谈模型层 | 我方无位置，沦为分包 | **先摊开六层**再谈分工 |
| L3 | 假设数据可自由使用 | 方案不可行 | **最先确认数据出域边界** |
| L4 | 忽略保密资质 | 人到现场进不去 | 入场前核实资质；备"客户执行+外部供方法"兜底 |
| L5 | 同名不同主体 | 谈错合作方 | 核实全称（智谱华章 ≠ 中航智谱） |
| L6 | 不引用客户上级语言 | 显得不懂客户 | 抓上级公开会议原文做骨架 |
| L7 | 一次想推十个领域 | 资源分散、全不成 | **先做 1 个领域样板**，成范式再复制 |
| L8 | 只讲模型指标不讲业务闭环 | 训完没人用 | 场景准入与验收指标**前置到第一页** |
| L9 | 忽视客户手上有硬任务 | 错过最大公约数 | 从上级要求里找客户的**硬任务与时间表** |

## 七、模板 A：六层分工总表

| 层 | 做什么 | **客户** | **模型方** | **我方** |
|---|---|---|---|---|
| ① 模型层 | 基座选型、微调、蒸馏、评测 | 提供领域语料、术语、**专家判断与评测标准** | **★主责**：基座、训练框架、算力、评测工具链 | 把知识结构化为**可训练语料**；组织评测集与验收口径 |
| ② Agent 层 | 智能体创建/管理/优化、多智能体协作、过程记录与结果验证 | 明确业务角色权限、"谁复核、谁签发" | 提供推理接口与工具调用能力 | **★主责**：系统级智能体、自助创建/管理/优化、多智能体协作、过程记录与结果验证 |
| ③ 数据层 | 领域数据集、知识资产、业务本体 | **提供数据源与密级判定**；授权范围 | 提供清洗/训练管道工具 | **★主责**：业务本体、数据集构建规范、知识资产化 |
| ④ 平台层 | 算力、平台、工具链、涉密部署环境 | 提供内网与机房；落实合规 | 提供本地化部署方案（离线/气隙） | 提供部署实施与集成；**不重复建设平台** |
| ⑤ 场景层 | 高价值、可闭环、可验证的业务闭环 | **★牵头**：选场景、指定业务责任人、验收成效 | 提供模型侧调优支持 | **★主责**：FDE 深入业务前线，拆成可实施可验收的闭环 |
| ⑥ 机制层 | 组织、责任矩阵、评估、培训、能力移交 | **★牵头**：设"AI 建设岗"、纳入既有体系 | 提供模型使用培训 | **★主责**：责任矩阵、评估机制、培训、**能力移交** |

## 九、模板 C：三阶段节奏

| 阶段 | 时间 | 目标 | 交付 |
|---|---|---|---|
| **速赢** | 3–6 月 | 选 **1 个具体场景**打通闭环 | 领域模型 v1 + 1 个业务闭环 + 验收数据 |
| **样板** | 6–12 月 | 做成**可复制范式** | 范式文档 + 责任矩阵 + 数据集规范 |
| **复制** | 12 月+ | 横向复制到其他部门 | 场景模板 + 培训体系 + 客户自主运营能力 |
