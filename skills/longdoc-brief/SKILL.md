# 长文一页纸（brief）：阅读版 + 传阅版

> 本技能由 FDE 工作台插件注册（`skills/longdoc-brief/`）；`fde-solution` / `fde-delivery` 的长文产物引用本技能。

## 定位

长文正文保留。另配一份**一页纸（brief）**。一页纸是长文的单页摘要，不是标准说明，也不是目录。

读者拿一页纸就能做判断，不必读长文。长文与一页纸冲突时，以长文 md 为准。

## 术语（先统一叫法）

| 叫法 | 指什么 | 不是什么 |
|---|---|---|
| **长文** | 正文 md，唯一事实源 | 不是一页纸 |
| **一页纸（brief）** | 长文的单页摘要，固定 7 块 | 不是目录、不是标准说明、不是第二份长文 |
| **阅读版** | 一页纸的交互 HTML 形态。屏幕阅读用；打印也只出一页 | 不是另一种内容 |
| **传阅版** | 一页纸的 A4 单页 HTML 形态。打印、转发用 | 不是另一种内容 |

不再造新名字：

- 「一页摘要」是「一页纸」的口语说法，**同一个东西**，不单独当名词用。
- 「交互版」改叫「阅读版」；「一页版」改叫「传阅版」或「传阅版预览」。
- 「内部传阅版」= 传阅版；「内部」只说明用途，不是名字。

## 触发时机

- 交付 ≥5 节的长文：报告、方案、评估、复盘、调研。
- 用户说：一页纸、brief、一页摘要、传阅版、内部传阅、给我个 HTML、做成能点的。
- 已有长文，要压缩给领导、客户或团队看。

## 输入

| 输入 | 必须 | 说明 |
|---|---|---|
| 长文 md 路径 | 是 | 唯一事实源。没有就先写长文，不要直接编一页纸 |
| 读者与用途 | 是 | 内部传阅 / 会前决策 / 客户汇报。客户汇报先改密级 |
| 密级 | 是 | 客户卷默认 L3 内部件；外发必须由人确认 |
| 主题与日期 | 是 | 用于命名与页脚 |
| 关键数字 | 是 | 至少 3 个硬数字，必须能在长文里找到 |

## 步骤

1. **先定长文 md。** 检查长文有结论、依据、边界与「方法与局限」。没有就补齐。不要用一页纸代替长文。
2. **提炼 7 块。** 按顺序：
   1. 一句话结论（≤60 字）
   2. 3 个关键数（支撑结论）
   3. 判断表（每个候选项一行：判定 + 一句依据）
   4. 建议（主攻 / 次选 / 保底 / 不做；每项带前置条件）
   5. 要人拍板的事（3–5 条，每条一句）
   6. 风险 top 3
   7. 元信息（密级、日期、来源长文）
3. **写一页纸正文。** 按本技能「写作口径」。数字、引语、单位原样引用，不换算、不合并。
4. **生成阅读版（交互 HTML）。** 自包含单文件。放到 `research/<客户>/<阶段>/exports/<主题>-brief.html`。要求：
   - 6 个页签：结论 / 逐项判断 / 评分或依据 / 建议 / 会前动作 / 传阅版
   - 深浅色切换、复制纯文本摘要、会前事项勾选（本地保存）
   - 键盘 `1–6` 切页签、`P` 打印、`T` 换主题
   - 打印时只输出传阅版，A4 单页，无导航与按钮
   - 无外部字体、脚本、图片依赖；离线可开
5. **生成传阅版（A4 单页）。** 独立 HTML，A4 单页，无交互，可直接打印或转发。放到 `...-brief-传阅版.html`。
   - 版式：标题 + 一句话结论 + 3 个指标 + 判断表 + 建议 + 拍板事项 + 风险 top 3 + 时间轴 + 页脚
   - 页脚只放：来源长文、日期、密级
6. **验证。** 必须跑两项：
   - 一页：在工作区根目录跑 `bash research-workbench-plugin/skills/longdoc-brief/assets/check-onepage.sh <传阅版.html>`，输出 `PASS: 1 page A4`。阅读版打印同样验 1 页。
   - 内容：对照长文抽查 3 个数字；检查成品没有自评分数、标准说明、认证声明。
7. **落盘与回报。** 更新客户卷 `00-项目档案.md` 索引。回报 ≤300 字，给阅读版、传阅版、长文三条路径。

> 版式基线：可从最近一份已交付一页纸复制版式，再替换内容与中性色。**不要跨客户复制数据或判断。**

## 产物与命名

| 产物 | 路径 |
|---|---|
| 长文 | `research/<客户>/<阶段>/<主题>.md`（唯一事实源） |
| 一页纸 · 阅读版 | `research/<客户>/<阶段>/exports/<主题>-brief.html` |
| 一页纸 · 传阅版 | `research/<客户>/<阶段>/exports/<主题>-brief-传阅版.html` |

> 文件名保留 `brief`：`brief` 就是一页纸。不要另造「一页纸.html」造成第四种叫法。

## 交互与版式要求

- **阅读版**：页签不是装饰，每个页签只回答一个问题，默认打开「结论」。打印样式单独写，`@media print` 隐藏交互层，只显示传阅版，`@page{size:A4}`。
- **传阅版**：无交互、无导航，打印出来就是 1 页 A4；可直接转发。
- 版式优先级：判断表 > 指标卡 > 建议卡 > 正文。一页内不出现两段以上连续长段落。
- 颜色不写死客户品牌色。用中性深色 + 一个强调色 + 一个辅助色。
- 动效克制：只做进入淡入与进度条；尊重 `prefers-reduced-motion`。
- 可访问：语义标签、`aria-selected`、焦点可见、对比度达标。

## 写作口径（STE 原则，内部目标）

- 中文单句 ≤35 字。超过就拆句。
- 一句一个动作或一个判断。条件、原因、结论不塞进同一句。
- 主动语态。执行者写清楚：我方 / 客户 / 系统。
- 一词一义。同一概念只用一个说法。缩写首次出现给全称。
- 一段 ≤6 句，一段只讲一件事。
- 警示、前提、边界单独成句或独立成块。
- 不写隐喻、口语、夸张、营销词、商业黑话。
- 客户原话、数字、单位、金额原样引用。
- **成品不写自评分数、标准说明、认证声明。** 写作自评只留在内部底稿，不进 HTML。

## 边界

- 不把一页纸做成目录或长文缩写。判断表与数字是主角。
- 不新增长文没有的结论。一页纸只能压缩，不能发明。
- 不把一页纸写成标准说明、方法论或技能介绍。
- 不给「一页摘要 / 交互版 / 一页版」再开新文档；它们是一页纸或它的两种形态。
- 不做对外发送。客户卷默认 L3；外发先改密级与措辞，由人确认。
- 不默认导出 PDF。只有用户明确要打印/存 PDF 时才导出。
- 不在成品里写「符合 ASD-STE100」「通过认证」；也不写自评分数与句长实测。

## 与其他规范的关系

- 写作规范：`research-workbench-plugin/reference/长文一页brief-写作规范.md`（7 块结构、验收清单）。
- STE 规则速查：`research-workbench-plugin/reference/ASD-STE100-简写标准-brief.md`。
- 视觉品味：`ui-taste` 技能。
- 长文正文写作：`human-writing` 技能（一页纸正文也应好读，但不追求文学性）。
